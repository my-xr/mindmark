# 07 领域模型与数据字典

> 文档状态：已重建为 UTF-8。更新时间：2026-07-19。  
> 本文定义考试闭环 P0/P1 所需核心领域对象、枚举、关系与数据约束。

## 1. 领域总览

```text
User / Role / Permission
  -> Course / Class / Student
  -> Question / Paper / Exam
  -> Submission / Answer / GradingTask / ScoreReport
  -> ReviewReport / LectureDraft / ExportArtifact
  -> AiProviderSetting / AiGenerationTask
  -> SecurityEvent / AuditLog
```

## 2. 用户与权限

### User

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `id` | string | 用户 ID |
| `username` | string | 登录账号；学生通常为学号 |
| `name` | string | 姓名 |
| `role` | enum | `ADMIN/TEACHER/TA/STUDENT` |
| `status` | enum | `ACTIVE/DISABLED/LOCKED` |
| `mustChangePassword` | boolean | 是否首次登录必须修改密码 |
| `createdAt/updatedAt` | datetime | 创建和更新时间 |

规则：

- 学生导入后默认密码为学号后 6 位。
- 已导入学生不可重复导入，按学号/账号去重。
- 教师、助教、管理员可按权限重置学生密码。
- 鉴权使用 Sa-Token，不使用 Spring Security。

## 10. 答卷级选项随机化与试卷冻结（2026-09-30）

### AnswerSheet.optionOrderJson

为保证单选题、多选题在每位学生答卷上的展示顺序可随机、刷新后稳定且可被正确判分，`answer_sheet` 新增以下字段：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `optionOrderJson` | text / JSON object | `questionId -> displayedOptionKey -> canonicalOptionKey` 映射 |

示例：

```json
{
  "question-001": {
    "A": "C",
    "B": "A",
    "C": "D",
    "D": "B"
  }
}
```

含义：学生页面仍展示 `A/B/C/D`，但显示键 `A` 对应题库原始 `C` 选项内容。学生提交的展示键先根据此映射还原为题库标准键，再参与自动判分。

规则：

1. 仅 `SINGLE_CHOICE` 和 `MULTIPLE_CHOICE` 写入随机映射；判断题、填空题和主观题不受影响。
2. 考试创建时即为每张答卷生成并持久化映射；重连、刷新、草稿保存均读取同一映射。
3. 历史已作答答卷若没有映射，按原始顺序补齐，避免旧答案被错误重解释。
4. 学生不可读取映射本身、标准答案、解析或评分点。

### PaperAnswerKey 与冻结约束

- 教师侧参考答案是试卷的派生视图：按题号返回题干、原始选项、分值、标准答案、解析、评分点和知识点。
- 试卷首次创建考试后自动从 `READY` 进入 `PUBLISHED`，并禁止再编辑题目、调整题序、修改状态或删除。
- 已被考试引用的题目同样禁止编辑；删除时保留历史考试引用并将题目停用，而不是破坏历史答卷、参考答案与判分依据。

## 11. 课程章节范围与阶段组卷（2026-10-09）

### CourseChapter

用于描述课程下的章节/教学单元，支撑“只从已讲章节出题”的期中、阶段测试和课后练习场景。

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `id` | string | 章节 ID |
| `courseId/courseName` | string | 所属课程与课程名称快照 |
| `chapterNo` | number | 章节序号，`0` 表示历史题目的“未分章”默认章节 |
| `title` | string | 章节名称 |
| `description` | string | 章节说明 |
| `status` | enum | `ACTIVE/DISABLED/ARCHIVED` |
| `createdAt/updatedAt` | datetime | 创建和更新时间 |

### Question 章节归属

`Question` 增加章节快照字段：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `chapterId` | string | 所属章节 ID |
| `chapterNo` | number | 所属章节序号，便于按第 1 章到第 8 章范围筛选 |
| `chapterTitle` | string | 所属章节名称快照 |

规则：

1. 新增/编辑题目时可选择课程章节；未选择时归入该课程 `chapterNo=0` 的“未分章”。
2. 题库检索支持按课程、章节、章节序号范围过滤。
3. 随机组卷和智能组卷规则支持 `chapterIds`、`chapterFromNo`、`chapterToNo`，后端在候选题查询层过滤。
4. 章节范围与题型、难度、知识点、分值规则同时生效，避免阶段考试抽到未授章节题目。
