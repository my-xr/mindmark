# 企业级的智慧教考评一体化平台-需求描述

## 1. 问题陈述（Problem Statement）

我想做一个集 教（课堂教学）→学(课后学习)→练(课后练习)→作（课后作业）→考(平时考试、期末考试)→画（学生画像，查漏补缺）六位一体的企业级的智慧教考评一体化平台。目前阶段最紧迫的任务是完成考试系统闭环。

**设计原则**：

- **统一工作台**：教师所有操作在单一系统完成，不跳系统
- **AI 优先**：所有重复性工作（出题、批改、总结）AI 先做，人审核
- **数据贯通**：考试、作业、课程行为数据统一沉淀到学生画像

## 2. 目标与非目标

### 2.1 目标（Goals）

| #    | 目标                                                         | 补充                                                        |
| ---- | ------------------------------------------------------------ | ----------------------------------------------------------- |
| G1   | **统一教学考试工作台**：教师在一个系统完成出题、组卷、监考、批改、发布成绩 |                                                             |
| G2   | **客观题秒级出分，编程/论述题 24h 内完成 AI 预批改**         | 客观题平均批改延迟 < 5s；编程题 AI 预批改覆盖率 > 90%       |
| G3   | **作业反馈周期从 2 周缩短至 3 天**                           | 作业平均反馈时长 < 72h；学生作业迭代次数 ≥ 2 次/份          |
| G4   | **建立课程知识图谱，支持个性化学习路径**                     | 知识点覆盖率 100%；薄弱知识点诊断准确率 > 80%               |
| G5   | **降低出题工作量 50%**                                       | AI 题目生成采纳率 > 60%；教师单题编写时间从 15min 降至 6min |

### 2.2 非目标（Non-Goals）

| #    | 非目标                                      | 理由                                                         |
| ---- | ------------------------------------------- | ------------------------------------------------------------ |
| NG1  | **不做代码沙箱运行环境**                    | 用户明确表示无需沙箱，编程题通过静态分析 + AI 评分；运行环境交给外部 OJ 或学生本地 |
| NG2  | **不做 MOOC 式公开课分发**                  | 本系统定位为单一教师/院校内部教学工具，不做对外的课程市场    |
| NG3  | **不做教务系统对接（学籍、培养方案）**      | 通过手动导入学生名单；对接教务系统作为未来的路线图项，短期不做 |
|      |                                             |                                                              |
| NG5  | **不做学术不端检测（论文查重 + 代码查重）** | v1.3 决策：代码查重也不做（原 v1.0 计划做，现砍掉）。文档查重更不做。聚焦考试闭环，查重非核心 |
| NG6  | **不做实时音视频直播课堂**                  | 录播视频上传 + 时间戳标注即可，直播交给腾讯会议/Zoom         |
| NG7  | **不做同伴互评（Peer Review）**             | 用户明确不做。作业批改由 AI + 教师/TA 完成，不引入学生互评（增加复杂度且评分质量难控） |
| NG8  | **不做代码 Review 作业类型**                | 用户明确不做。作业类型聚焦编程作业 + 实验报告两种，不做代码 Review 这种特殊作业形式 |
| NG9  | **考试闭环外的模块暂不做**                  | MVP 聚焦考试系统闭环。作业系统、练习系统、课程管理、学生画像的复杂部分放到考试闭环跑通之后 |

### 2.3 核心目标

**核心目标：教师能用这套系统完成"出题 → 组卷 → 开考 → 批改 → 出分 → 复盘"的完整闭环。**

1. **题库管理**
   - 题目 CRUD + 批量导入（Excel/Word/Markdown）
   - 题目元数据：知识点标签、难度、来源、得分点清单
   - 题库分类（公共/课程/个人）
   - 支持后置打标（不依赖完整知识图谱）
2. **AI 题目生成智能体**
   - 按知识点+题型+难度生成题目
   - **得分点拆解前置**（必输出字段）
   - 查重 + 答案校验 + 教师审核入题库
   - 面试题集/大厂笔试题导入辅助
3. **6 种核心题型**（单选/多选/判断/填空/简答/编程）
   - 客观题（单选/多选/判断/填空）：自动批改
   - 主观题（简答/编程）：AI 批改 + 教师复核
4. **三级批改机制**
   - 客观题：自动批改（秒级）
   - 编程题：AI 批改（按得分点逐项判定 + 静态分析 + 评语）
   - 简答题：AI 批改（要点匹配 + 教师复核）
   - 教师复核界面：查看得分点判定 + 一键接受/调整
5. **防作弊 L1-L3**
   - L1 基础：禁复制/右键/全屏
   - L2 标准：切屏检测 + 题序/选项随机
   - L3 严格：IP 白名单 + 单点登录 + 同卷不同题 + 数值参数化 + 行为审计回放（近几个版本都不做L3）
6. **考试生命周期管理**
   - 创建考试 → 配置参数 → 添加题目 → 预览 → 发布
   - 学生答题前端：草稿自动保存、倒计时、标记题、断线续考、交卷确认
   - 成绩发布 → 学生查分 → 申诉通道 → 归档入题库
7. **考试复盘（教师侧 + 学生侧）**
   - 教师：班级成绩分布、题目难度系数/区分度、知识点诊断、AI 试卷讲评稿
   - 学生：个人成绩 + 班级位置、错题归因、同知识点推荐
8. **通知与消息中心**（考试闭环必需）
   - 考试开始/结束前提醒、成绩发布通知
   - 多渠道（站内 + 邮件）
9. **RBAC 基础权限**
   - 教师/TA/学生/管理员基础权限隔离
   - 学生数据隔离
10. **基础学生画像**（仅接收考试成绩）
    - 考试成绩记录
    - 知识点掌握度初版（基于考试成绩）
    - 为后续画像扩展预留数据接口
