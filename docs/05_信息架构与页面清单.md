# 05 信息架构与页面清单

## 1. 信息架构原则

1. 教师端围绕考试闭环组织导航。
2. 学生端围绕“参加考试、查看反馈”组织导航。
3. 管理端仅保留 MVP 所需的组织、角色、基础配置入口。
4. 每个页面必须能映射到需求编号和业务流程节点。

## 2. 角色入口

| 角色 | 默认入口 | 说明 |
| --- | --- | --- |
| 管理员 | 管理员登录 → 管理控制台 | 管理用户、角色、课程和审计。 |
| 教师 / TA | 教师登录 → 教师工作台 | 查看考试筹备、批改、成绩和复盘任务。 |
| 学生 | 学生登录 → 学生考试中心 | 查看待参加考试和成绩反馈。 |

登录入口路由：

```text
/auth/entry/8b7f2d4c91e6a3f0c5d8b1e7  管理员登录
/auth/entry/3e9a6c1f74b8d205a7c4f0e2  教师 / TA 登录
/auth/entry/6d2c8a5f1b9e4d70c3a6f8e1  学生登录
```

登录页面不展示跨角色切换链接。三个地址不包含管理员、教师或学生等角色语义，应由部署或组织管理员分别分发。旧地址 `/auth/login` 仅保留兼容：无目标地址时跳转到教师登录页，带有管理端/学生端 `redirect` 时跳转到对应登录页；未登录访问具体业务端时，系统按目标端自动跳转到对应登录页。

## 3. 导航结构

### 3.1 教师端

```text
教师工作台
├─ 题库管理：题目列表、新建/编辑题目、AI 出题审核、批量导入
├─ 试卷与组卷：试卷列表、组卷编辑器、试卷预览
├─ 考试管理：考试列表、创建/编辑考试、考试监控、考试设置
├─ 批改中心：批改任务列表、主观题复核、批改审计
├─ 成绩中心：成绩列表、发布前检查、申诉处理
├─ 复盘分析：班级分析、题目分析、知识点诊断、AI 讲评稿
└─ 消息中心
```

### 3.2 学生端

```text
学生考试中心
├─ 待参加考试
├─ 考试须知
├─ 在线答题
├─ 提交回执
├─ 成绩与反馈
├─ 错题与知识点建议
└─ 我的申诉
```

### 3.3 管理端

```text
管理控制台
├─ 用户与角色
├─ 课程与班级
├─ 模型服务配置
├─ 通知配置
└─ 审计日志
```

## 5. 页面验收通用标准

- 有明确页面标题、主操作、筛选区、内容区和状态反馈。
- 表格页面具备空状态、加载状态、错误状态和分页预留。
- 表单页面具备必填校验、保存反馈和取消确认。
- 涉及 AI 的页面必须展示 AI 状态、置信度或风险提示、人工操作入口。
- 涉及成绩和批改的页面必须避免误操作，关键动作二次确认。
- 三类登录页必须明确标识当前端，提交后校验账号角色与入口匹配；角色不匹配时不得进入错误端。
- 页面文件建议不超过 400 行，超出时拆分组件或 composable。

## 6. 后续维护规则

新增页面时必须补充：页面编号、角色、优先级、关联需求、核心说明和验收点。
