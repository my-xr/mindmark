# 13 术语表

## 1. 项目术语

| 术语 | 说明 |
| --- | --- |
| MindMark | 项目英文名。 |
| 明镜台 | 项目中文名，寓意看清学习过程、考试结果和知识掌握状态。 |
| 教考评一体化 | 覆盖教学、学习、练习、作业、考试、画像的综合平台方向。 |
| 考试闭环 | 出题 → 组卷 → 开考 → 批改 → 出分 → 复盘。 |
| MVP | 当前最小可用产品范围，聚焦考试系统闭环。 |

## 2. 业务术语

| 术语 | 说明 |
| --- | --- |
| 题库 | 存放题目的集合，可按公共、课程、个人分类。 |
| 题目 | 考试或练习中的最小作答单元。 |
| 题型 | 单选、多选、判断、填空、简答、编程。 |
| 得分点 | 主观题或编程题评分时的细分判定项。 |
| 试卷 | 由一组题目、分值和结构组成的考试内容载体。 |
| 考试 | 面向班级或学生发布的考试活动，包含时间、规则、试卷和参与者。 |
| 答卷 | 学生在一次考试中的作答记录。 |
| 批改任务 | 针对答卷或题目的评分任务。 |
| AI 预批改 | 由大模型先给出分数、得分点命中和评语，等待教师复核。 |
| 复核 | 教师或 TA 对 AI 批改结果进行确认或调整。 |
| 成绩发布 | 教师确认批改完成后，将成绩开放给学生查看。 |
| 申诉 | 学生对成绩或批改结果提出复查请求。 |
| 复盘 | 考试结束后对成绩分布、题目表现、知识点掌握情况进行分析。 |
| 学生画像 | 基于考试、作业、练习等数据形成的学生学习状态描述。 |

## 3. 技术术语

| 术语 | 说明 |
| --- | --- |
| RBAC | 基于角色的访问控制。 |
| Provider / Adapter | 大模型服务供应商抽象与适配层。 |
| RAG | 检索增强生成，后续用于知识库、题目查重和讲评增强。 |
| Mock | 在真实后端完成前，用模拟数据支撑前端开发。 |
| 审计日志 | 记录关键操作的日志，用于追踪责任和排查问题。 |
| Redis | 缓存 / 临时状态系统，用于答题草稿、倒计时、限流等。 |
| PostgreSQL | 项目主数据库。 |
