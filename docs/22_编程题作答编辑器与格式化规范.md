# 编程题作答编辑器与格式化规范

更新时间：2026-07-21

## 1. 目标

- 学生考试页中，编程题使用专用代码编辑器，不再使用普通多行文本框。
- 支持 Java、JavaScript、Python、YAML / YML 的语法高亮。
- 支持考试场景下的保守自动格式化，避免格式化破坏学生代码语义。
- 不改变现有答卷草稿保存和交卷契约：当前仍保存源码字符串，避免影响考试闭环。

## 2. 前端实现范围

- 新增组件：`apps/mindmark-web/src/components/exam/ProgrammingCodeEditor.vue`。
- 新增类型：`apps/mindmark-web/src/types/programming.ts`。
- 新增样式：`apps/mindmark-web/src/styles/code-editor.css`，并由 `styles/index.css` 统一引入。
- 学生答题页：`apps/mindmark-web/src/views/student/ExamTakingView.vue` 在题型为 `PROGRAMMING` 时渲染代码编辑器。

## 3. 交互规范

- 顶部工具栏包含语言选择与格式化按钮。
- 支持行号、代码高亮、自动换行、字符数和行数提示。
- 未进入全屏或考试不可编辑时，编辑器进入只读状态。
- 切换题目后保留该题的语言选择状态。

## 4. 格式化策略

- Java / JavaScript：基于括号、分号、缩进的保守格式化；会避开字符串、模板字符串、行注释和块注释。
- Python：仅清理行尾空格、压缩多余空行，不主动改写缩进结构。
- YAML / YML：Tab 转 2 空格、清理行尾空格、压缩多余空行。

## 5. 后续增强建议

- 与 OJ / Sandbox 提交契约打通时，将语言字段与源码一并提交。
- 如需更强格式化，可在非考试态引入 Prettier / Black / Google Java Format 的服务端格式化能力。
- 后续可增加字体大小、主题、自动补全开关等学生个人偏好配置。
