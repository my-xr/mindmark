# 23_教师学生端真实体验巡检记录

## 2026-07-22 巡检范围

本轮不继续扩展 AI 能力，重点做教师端与学生端完整体验巡检，覆盖真实后端、真实数据库、真实 AI Provider 配置下的考试闭环。

## 巡检环境

- 后端：本地 Spring Boot，端口 `18084`。
- 数据库：本地 `mindmark` PostgreSQL。
- Redis：本地 6379。
- 前端：Vite + Playwright，`VITE_USE_MOCK=false`，代理到 `http://localhost:18084`。
- AI Provider：以 OpenAI 兼容方式连接 Moonshot/Kimi，模型 `kimi-k2.6`，密钥通过本地环境变量传入，不写入代码和文档。

## 教师端页面巡检

执行命令：

```powershell
$env:VITE_USE_MOCK='false'
$env:VITE_API_PROXY_TARGET='http://localhost:18084'
$env:MINDMARK_API_BASE_URL='http://localhost:18084'
pnpm --filter mindmark-web exec playwright test e2e/teacher-pages.spec.ts --project=teacher-chrome --reporter=line
```

结果：`14 passed`。

覆盖页面：

1. 教师工作台
2. 题库管理
3. AI 出题审核
4. 试卷与组卷
5. 考试管理
6. 学生名单与账号
7. 批改中心
8. 成绩中心
9. 考试复盘与 AI 讲评
10. 个人配置

覆盖检查点：

- 页面可加载。
- 左侧导航 active 状态唯一。
- 页面无 `MM-500-001`、`Unhandled` 等错误提示。
- 主要按钮具备可访问名称，不存在只显示图标但无文本/aria/title 的可见操作。
- 页面无 body 级横向溢出。
- 关键按钮轻量点击不触发运行时错误。
- 题库抽屉查看/编辑、加入试卷入口可打开关闭。
- AI 出题审核生成模块、任务历史刷新、个人配置入口可用。
- 试卷与组卷、考试管理、成绩中心核心按钮可用。

## 100 分真实考试闭环复验

执行命令：

```powershell
powershell -ExecutionPolicy Bypass -File scripts/api-smoke/run-100-point-exam-smoke.ps1 `
  -BaseUrl http://localhost:18084 `
  -AiJobTimeoutSec 240 `
  -AiProvider OPENAI `
  -AiProviderBaseUrl https://api.moonshot.cn/v1 `
  -AiProviderModel kimi-k2.6 `
  -AiProviderApiKeyEnvName KIMI_API_KEY `
  -RequireAiSucceeded
```

结果：通过。

关键数据：

- 创建题目：56 道。
- 试卷总分：100 分。
- 试卷题量：56 道。
- 客观题：50 道，自动判分。
- 主观题/编程题：6 道，AI 批改任务成功。
- AI Job 状态：`SUCCEEDED`。
- 批改任务状态：`AI_CHECKED`。
- 教师确认成绩：100 分。

## 当前结论

教师端和学生端核心体验已完成真实后端巡检，考试闭环可用。当前不再扩大 AI 能力，后续应优先进入企业级细节巡检：真实浏览器视觉验收、批量数据下的页面性能、异常场景提示、以及演示数据清理和日志收敛。

## 下一轮建议

1. 做一次真实浏览器人工视觉验收，重点检查页面间距、表格列宽、抽屉/弹窗、按钮状态和移动端窄屏表现。
2. 用 100+ 学生、500+ 题目、50+ 试卷/考试批次进行批量数据压测，验证分页、筛选、排序和首屏耗时。
3. 收敛本地测试数据，避免 Smoke/E2E 多次运行后影响页面演示数据质量。
4. 上线前关闭不必要 DEBUG 日志，避免生产运行日志过大。
